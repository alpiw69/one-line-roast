## What this is

One line, roasting the gadget I use every day, my phone:

> My fingerprint sensor fails every morning, like it doesn't recognize me before coffee either.

The phone is as groggy as its owner first thing in the morning. It names a real daily gadget, the failure is a concrete thing that actually happens every day, and the twist lands in the last few words instead of just grumbling about a bad sensor.

Why this line and not the obvious one: it avoids the worn complaints the brief itself lists, the phone dying at four in the afternoon and the app begging for a rating. The fingerprint sensor failing before coffee is a specific personal gripe with a fresh turn, and it needs no setup to land.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the line to `/output/entry.txt`.

```bash
python3 main.py
```
